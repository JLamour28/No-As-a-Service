# The Ultimate "NO" Button 🚫

> When you need a creative excuse to decline anything in life

A fun, interactive web app that generates hilarious reasons to say "NO" to just about anything. Perfect for declining meetings, social events, and questionable life choices!

## 🎯 Features

- **One-Click Excuses**: Generate creative reasons to say "NO" with a single click
- **Beautiful UI**: Smooth animations and modern gradient design
- **Stats Tracking**: Keep track of how many times you've said NO
- **Keyboard Shortcuts**: Press `Space` or `N` for quick access
- **Persistent Stats**: Your total NO count is saved locally
- **Responsive Design**: Works great on mobile and desktop

## 🛠️ Technical Details

Built with vanilla JavaScript, HTML, and CSS. Uses the [NO API](https://naas.isalman.dev/no) by [Salman](https://github.com/isalmanhaider).

- **API**: `https://naas.isalman.dev/no`
- **Rate Limit**: 120 requests per minute per IP
- **Response Format**: JSON with a `reason` field

## 📝 Example API Response

```json
{
  "reason": "This feels like something Future Me would yell at Present Me for agreeing to."
}
```
